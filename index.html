Used Laptop Testing Hub

Complete this checklist before buying a secondhand or refurbished laptop.

Keyboard

Slide through every single clickable key. Key-Test may work for both Windows and macOS.

ZFrontier Keyboard Tester Key-Test
Trackpad

Drag click an item on Desktop and slide on the trackpad randomly to check any issues.

Webcam

Use the built-in Camera app will do. Otherwise, you may use the webcam tester.

Webcam Tests
Microphone

Use the built-in Sound Recorder app. Otherwise, you may use the microphone tester.

Microphone Test
Speakers

Play audio to test maximum volume and Left/Right stereo balance.

Stereo Sound Test
Display

Check for dead/stuck pixels.

Screen Test YouTube 4K HDR 60fps
Storage

1. Use CrystalDiskInfo to check the health of the SSD/HDD.

2. Open cmd and run Get-PhysicalDisk. Check for "OperationalStatus" and "HealthStatus".

CrystalDiskInfo
RAM

Need to prepare a empty usb flash drive for the test. To verify total RAM capacity and check for memory errors.

Memtest86
Battery Health

Open cmd and run powercfg /batteryreport to check wear level. Check the output line for report location.

Open the report and search for "DESIGN CAPACITY" and "FULL CHARGE CAPACITY" for healthy percentage.

BIOS (Especially ThinkPads)

Restart and enter BIOS. Go to Security -> Password, make sure all disabled. Under Security, go Anti-Theft -> Computrace, Current Setting Disabled.

Bluetooth

Try to connect a bluetooth headphone, mouse, keyboard or anything else to check.

Wi-Fi

Connect to any Wi-Fi or hotspot and run a speedtest to ensure the Wi-Fi working.

Ookla Speedtest
Serial Number

Verify the SN on the bottom chassis matches the BIOS, and check official warranty status.

Lenovo Acer MSI ASUS Apple HP Dell Honor Huawei
Physical Ports

Plug and test charging port, USB-A, USB-C, HDMI, Audio Jack, Audio-Mic Combo Jack, Ethernet port, sd card slot,

Fingerprint Scanner

Win+I to open settings -> Accounts -> Sign-in options -> Fingerprint recognition (Windows Hello) -> Set up.

To see whether the scanner works properly, try using it to unlock the laptop.

Pressure Testing

Run FurMark to do a intensive GPU stress test for about 15 to 30 minutes.

FurMark
Have fun with your new laptop!
